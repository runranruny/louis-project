## ② 天使（ハンター）｜A：ギャップ ― 今日の初投稿に推奨
- 感情の変化：かわいい → え、狩り？ → 結局かわいい
- フック（0〜1秒）：18.0秒の顔アップ（ネズミをくわえた青い目）を静止させ、テロップ「天使…？」
- 展開：「15秒前」→ 0〜14秒の狩り（突撃・寝転がり・パンチ）を1.5倍速 → 15〜17秒、カメラに突進（ブレ）
- オチ：18.0〜19.5秒の顔アップを0.6倍スローで、ゆっくりズーム。テロップ「獲物、見せに来ました（褒めて）」
- 尺：約13秒
- 撮影素材：追加不要
- 仮説：結論の顔を先に見せる冒頭は、2秒時点の維持率を上げる

## ③ ルイス失踪事件｜B：事件簿
- 感情の変化：え？ → いた！ → その顔は何
- フック（0〜1.5秒）：黒い画面にテロップ「【事件】ルイスが家から消えた」。ニュース風の効果音
- 展開：0〜5秒、棚の箱の中からじっと見てくる顔へズーム。テロップ「…いた」→「ようやく見つけたか👀（容疑者談）」
- オチ：6〜11秒、立ち上がって棚の上へ → 11.6秒にカメラを見上げる。テロップ「容疑者、反省の色なし。かわいいので無罪」
- 尺：約12秒
- 撮影素材：「部屋を探している」2〜3秒のカット（誰もいない部屋を映すだけ）があるとより良い。なければ黒い画面で代用
- 仮説：事件簿の型（事件→証拠→無罪）は、コメントやシェアにつながりやすい
- 注意：探した時間などは、実際の数字だけを書く（盛らない）

## ① 王子は寝たまま遊びます｜C：王子と下僕
- 感情の変化：かわいい → 下僕がかわいそう → 王子の勝ち
- フック（0〜2秒）：寝転がったまま前足だけ動くカット。テロップ「下僕、全力で振ってます」
- 展開：猫じゃらしが揺れるたびに、前足だけで対応（3〜23秒を要所だけ切り出し、2倍速も混ぜる）。テロップ「起き上がる気配なし」
- オチ：26〜28.5秒、仰向けで獲物を抱えたままカメラ目線。テロップ「本日の運動量：前足のみ」
- 尺：約12〜15秒
- 撮影素材：追加不要（下僕の腕が映るカットがあればさらに良い）
- 仮説：飼い主目線の自虐は、共感からの保存・シェアにつながる

## ④ おかえり（起きるとは言ってない）｜A：ギャップ
- 感情の変化：出迎えてくれた！ → 寝てる → 指はガジガジ → かわいいので許す
- フック（0〜2秒）：2.4秒のカメラ目線の寝ぼけ顔。テロップ「帰宅したら出迎えてくれた」
- 展開：寝転がったまま → 12〜24秒、指に肉球で応戦 → 33.5秒ごろ指を甘噛み。テロップ「ただし起きるとは言ってない」
- オチ：35〜38秒の何事もなかった顔。テロップ「おかえりの顔だけは100点」
- 尺：約12秒
- 撮影素材：追加不要。**横向きの動画なので、CapCutで9:16に切り抜く**（ルイスが中央右寄りに来るように）
- 仮説：「帰宅・出迎え」は飼い主の共感が強く、保存されやすい

## 安全チェック
4本とも、ルイスが自分から遊んだり休んだりしている自然な映像で、驚かせる・怖がらせる演出はない。③の棚の高さも普段の行動の範囲内。
