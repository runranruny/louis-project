## CapCutでの手順（iPhone）
1. 新規プロジェクト → IMG_2314 を読み込む（縦なので比率は9:16のまま）
2. **冒頭のフリーズ**：再生ヘッドを18.0秒に合わせる →「編集」→「フリーズ」→ できた静止画を先頭へドラッグ → 長さ1.8秒
3. **切り分け**：元動画を表の「元の秒」で分割し、使わない部分（0–1.3秒、2.4–3.0秒、13.0–14.0秒、17.0–18.0秒、19.5秒以降）を削除
4. **速度**：各クリップをタップ →「速度」→「標準」で表の倍率に設定（3.0–3.7秒は0.6倍、18.0–19.5秒は0.5倍。スロー時は「スムーズスロー」をオン）
5. **ズーム**：冒頭とオチのクリップでキーフレームを2つ打ち、最初の点を1.0倍、最後の点を1.1倍（オチは1.3倍）にする
6. **間**：8.6–9.2秒の静止部分ではBGMを分割してミュートし、効果音も置かない
7. **テキスト**：「テキスト」→ 太めの丸ゴシック、白＋黒フチ。画面下3分の1、UI（いいねボタン等）にかからない位置に置く。表示タイミングは表のとおり
8. **効果音**：「オーディオ」→「効果音」で検索（キラーン／巻き戻し／ドン／ドタバタ／ポワン）
9. **BGM**：アプリ内の音源から、かわいい系の曲を音量30%で。TikTokはTikTokアプリ内の音源に差し替えるとおすすめに乗りやすい
10. **書き出し**：1080p・30fps

## テンプレート化のポイント（目標：テンプレート3種のうち1本目）
「結論の顔を先に見せる → ◯秒前 → 本編を倍速 → 無音の間 → スローの顔でオチ」は、ほかの素材でも使い回せる。CapCutで完成後に「テンプレートとして保存」しておく。
